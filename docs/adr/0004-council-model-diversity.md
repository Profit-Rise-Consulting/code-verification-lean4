# 0004. Phase 2 council uses multiple model families and argues sub-claims separately

## Context and Problem Statement
The hypothesis is compound: "LEAN4 cannot verify protocols AND therefore unable to check code implementation of these protocols." A single model, or a single model family, tends to converge on its own priors. The owner prefers independent and adversarial review in a different harness or model family.

## Decision Outcome
- The council debates sub-claims H1-H5 and the definitions question D separately (research/CONVENTIONS.md), then the compound motion.
- Proposition, opposition and judges must come from at least three different model families. Judges must not share a family with either advocate.
- Only [FULL] or [CODE] evidence may be cited, by source ID.
- Details: docs/phase2/council-kit.md.

### Consequences
- Good: verdicts can be partial ("H1 false, H3 partly true"), which is more useful for Phase 3 than a binary answer.
- Bad: higher cost and orchestration effort.
